# 체험 공간 설정 API

체험 공간(가로·세로·벽 여유·출발점)은 **Server 가 단일 출처**다. Client 는 조회해서 미리보기·시뮬레이션에, Agent 는 조회해서 위치 안전 검사에 쓴다.
설정이 한 번도 저장되지 않았으면 `6x6-박람회`(지금까지의 값)를 돌려준다 → 설정을 쓰지 않으면 동작이 이전과 같다.

## API
| 메서드·경로 | 권한 | 설명 |
|---|---|---|
| `GET /api/v1/arena-settings` | 공개 | 현재 설정 + `limits`(가용 영역·1회 이동 한도·기본 이동 거리) + `updatedAt`(저장된 적 없으면 null) |
| `GET /api/v1/arena-settings/presets` | 공개 | 프리셋 2종 |
| `PUT /api/v1/admin/arena-settings` | 관리자 세션 + CSRF | `{"presetCode":"3x3-부스"}` 또는 개별 값 6개(`widthM, depthM, marginM, startXM, startYM, startHeading`). 둘을 섞으면 400 |
| `GET /api/v1/admin/arena-settings/history` | 관리자 세션 | 변경 이력(최근 50건): 누가(`admin-session:<id>`)·언제·이전 값 → 새 값 |

## 프리셋
| 코드 | 크기 | 벽 여유 | 출발점 | 가용 영역 | 1회 최대 이동 | 이동 블록 기본값 |
|---|---|---|---|---|---|---|
| `6x6-박람회` | 6×6 m | 0.4 m | (5.6, 0.4) +Y | 5.2×5.2 m | 3.0 m | 1.0 m |
| `3x3-부스` | 3×3 m | 0.5 m | (2.5, 0.5) +Y | 2.0×2.0 m | 1.2 m | 0.5 m |

## 값 검증
- 한 변 2.0~6.0 m, 벽 여유 0.4~1.0 m(Agent 하드 상한: 한 변 6 m·벽 여유 0.4 m 이상보다 넓지 않다), 가용 영역(변 − 2×여유) ≥ 1.3 m.
- 출발점은 벽 여유 안쪽. 방향은 `+Y|+X|-Y|-X`.

## 파생 값(자동 계산)
- `maxMovePerCommandM = min(3.0, 0.1 단위 내림(가용 영역의 짧은 변 − 0.8))` — 한 번 이동한 뒤에도 제자리 회전 지름 0.8 m 가 남아야 한다.
- `defaultMoveDistanceM = clamp(0.5 단위 내림(maxMove / 2), 0.5, 1.0)`.
- 블록 검증(#118)의 이동 블록 최대 거리, `GET /api/v1/blocks` 의 이동 블록 `max`, AI 초안 검증의 이동 거리 상한이 이 값을 따른다. 총 이동 4 m·총 시간 120 s 상한은 공간과 무관하게 그대로다.
- 회전 각도(1~360°)·대기·반복 범위는 바뀌지 않는다.

## 운영 시 주의
- 마이그레이션 `V20` 이 테이블 2개를 만든다(행이 없으면 기본값). 이 PR 을 develop 에 머지하면 CD 가 돈다.
- 공간을 바꿔도 이미 저장된 프로그램을 다시 검증하지 않는다. 실행 시점 검증과 Agent 위치 검사가 최종이다.
- **Agent 는 설정으로 안전을 넓힐 수 없다**(자체 하드 상한이 항상 우선). Server 값이 더 넓어도 Agent 는 거부한다.
